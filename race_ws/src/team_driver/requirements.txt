#   scikit-learn==1.3.2

#
# CAUTION - do not pin any of these:
#
#   python-socketio   python-engineio   gevent   gevent-websocket   greenlet
#
# The devkit's websocket bridge is pinned to old versions of them on purpose
# (docker/devkit-requirements.txt explains why). Replace one and the bridge
# connects to the simulator and then publishes nothing at all, silently, for
# the whole run - which looks like a dead simulator, not a dependency clash.
# Replacing numpy or transforms3d breaks it in a different way: ROS 2 Humble's
# own packages are built against the versions apt installs.

#
